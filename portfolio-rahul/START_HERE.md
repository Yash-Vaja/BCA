## Welcome to Your New Portfolio! 🎉

This is your complete, professional portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Quick Start (3 Steps)

### 1. Install Dependencies
```bash
cd portfolio-rahul
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Open in Browser
Visit: **http://localhost:3000**
